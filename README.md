# Personal Portfolio Website

A clean, modern, and responsive personal portfolio website built with semantic HTML5 and CSS3 to showcase projects, skills, and background.

---

## 🚀 Live Demo

- **GitHub Repository**: [https://github.com/hritikraj07/portfolio-project](https://github.com/hritikraj07/portfolio-project)

---

## 📌 Features

- **About Me**: Brief introduction and background in Computer Science & Engineering (AIML).
- **Skills Matrix**: Clear overview of technical proficiencies.
- **Projects Showcase**: Interactive list of featured projects, including:
  - **Portfolio Website**: Personal showcase site.
  - **Galaxy Defender**: Space-themed arcade game.
  - **Code Flux**: Digital studio web project.
- **Contact Form**: Direct message section for inquiries.
- **Responsive Navigation**: Smooth navigation linking to key sections.
- **Modern Typography**: Styled using Google's Poppins font family.

---

## 🛠️ Built With

- **HTML5**: Semantic markup for layout and accessibility.
- **CSS3**: Custom styling, layout design, typography, and responsive elements.
- **Google Fonts**: Poppins font family.

## 💻 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hritikraj07/portfolio-project.git
   ```
2. **Navigate into the project directory:**
   ```bash
   cd portfolio-project
   ```
3. **Open the project:**
   - Double-click `index.html` or open it with your browser.
   - Or run with a live server extension (e.g., Live Server in VS Code).
